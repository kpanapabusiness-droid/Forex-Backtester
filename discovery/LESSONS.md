# LESSONS

Operator-compressed distillation of the free-form log (dead families, transforms that never help, open
threads). Compressed **out-of-band by the operator** when the run is stopped (see
[`DISCOVERY_PROTOCOL.md`](./DISCOVERY_PROTOCOL.md) §6 / §9); discovery chats **READ** this at arc step (a)
but never write or compress it. Empty until the first compression.
